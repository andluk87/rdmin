# Application icons

Viewer: blue overlapping windows and pointer. Server: orange overlapping windows and return arrow.
Generated for this project from the user's visual reference. ICO contains 16, 24, 32, 48, 64, 128 and 256 pixel images; PNG masters are not runtime dependencies.
Embedded into the application executable, MSI and Setup. Windows forms and tray reuse the executable icon. No loose icon files are installed.
