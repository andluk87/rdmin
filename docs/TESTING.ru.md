# Проверка после сборки на VPS

Эти проверки подготовлены для выполнения заказчиком. В текущей задаче они не запускались.

1. Выполнить `bash scripts/build-vps.sh` на Linux x64 VPS. Проверить четыре артефакта и `sha256sum -c SHA256SUMS`.
2. На Windows 10/11 и Server 2019/2022/2025 проверить запуск ZIP целиком и установку/удаление MSI. Проверить Start Menu, DLL DXGI и работу без установленного .NET.
3. На двух Windows-машинах в LAN: включить Server, передать отпечаток и код, подключить Client. До локального согласия убедиться в отсутствии изображения и управления.
4. Изменённый отпечаток, неверный/истёкший/использованный код должны отклоняться. Отказ в consent не должен открывать экран.
5. Проверить View Only: mouse/key не исполняются; снять локальный флажок «Управление» — сессия разрывается. Повторное подключение требует нового кода и согласия.
6. Проверить клики, drag, колесо, Ctrl/Shift, русскую/английскую раскладку, отпускание при потере фокуса клиента, обрыве сети, закрытии клиента и остановке сервера.
7. Два монитора, разные DPI, отрицательные координаты, портретный монитор, 1920×1080: правильный монитор, соотношение сторон и координаты. Проверить GDI fallback и DXGI отдельно. UAC не должен обходиться; разрыв/ошибка допустимы для этого прототипа.
8. Передать 100 MiB, проверить SHA-256. Начать 2 GiB, прервать, заново открыть сессию и продолжить тот же файл. Изменённый частичный файл должен отклониться на SHA-256. Проверить пустой файл, отмену, upload/download, занятый файл, отсутствие overwrite.
9. Проверить `../`, `C:/`, UNC, ADS, reparse point, junction, hardlink, зарезервированные имена и выход за общую папку: отклоняются. Проверить local ACL отказ. Подтвердить удаление на обеих сторонах, отказ сохраняет файл.
10. Буфер: Unicode, размер 1 MiB, запрет при отсутствии права, отсутствие циклов. Чат не должен попадать в audit.
11. Разорвать сеть и закрыть сервер: удерживаемые кнопки отпускаются, клиент очищает изображение. Повторное подключение — новая подтверждаемая сессия.
12. Проверить malformed JSON, неверную версию, длину >8 MiB и неизвестный тип пакета: безопасное завершение, без исключения процесса и утечки ключа.

## Автоматические исходники проверок

`tests/Checks.csproj` — Windows console harness для протокола, DPAPI identity и файловой политики. На Windows с .NET SDK 8:

```powershell
dotnet run --project tests/Checks.csproj -c Release
```

Это запускает сборку и тесты только по вашей команде на Windows; в данной задаче не выполнялось.

## Фиксация результата

Запишите версию Windows, GPU/драйвер, режим DXGI/GDI, DPI/мониторы, сеть, размеры файлов, SHA-256, результаты каждой проверки и время. Производительность и соответствие исходному ТЗ не заявляются до измерений и реализации пунктов STATUS.ru.md.
