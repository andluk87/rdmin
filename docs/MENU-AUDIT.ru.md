# Аудит команд 0.5.0

Проверены обработчики и условия в исходниках. Ни одна строка ниже не означает успешного испытания на Windows. Сборку и запуск здесь не выполняли по требованию заказчика.

| Окно / меню | Действие и ограничения | Проверка на Windows после сборки |
| --- | --- | --- |
| Viewer / Соединение | Быстрое подключение, новое соединение, папки, вход, отключение, свойства, переименование, удаление, выход | Новый адрес, отмена входа, двойной щелчок папки/ПК, F7/Insert/F2/Delete/Alt+Enter; удаление только после согласия |
| Viewer / Режимы | Управление, просмотр, файлы, чат, питание, уведомление; сервер ограничивает запрошенные права | Проверить каждый режим с разрешением и без него; возврат управления после перехода в просмотр требует нового сеанса |
| Viewer / Вид | Четыре вида списка, скрытие дерева папок, сортировка колонок | Переключить все виды, проверить сохранение фильтра при обновлении |
| Viewer / Сервис | Экспорт, импорт JSON с лимитами, приглашение, забывание ключа выбранного ПК, каталог настроек | Экспорт/импорт с вложенными папками, повреждённый JSON, отмена выбора файла; забывание ключа с подтверждением |
| Viewer / Справка | Версия и актуальные ограничения | Сверить с версией MSI |
| Viewer / Контекстные меню | Режимы для ПК, свойства/переименование/удаление; создание/переименование/удаление папок в дереве | Правая кнопка по другой записи выбирает именно её; корень защищён; папку с соединениями удалить нельзя |
| Удалённый экран | Отключение, файлы, текстовый ввод, чат, питание, уведомление, полный экран, масштаб, просмотр, мониторы, качество, буфер | Проверить каждую кнопку; Esc выходит из полного экрана; 100% прокручивается; команды зависят от прав |
| Файлы | Обновление, вверх, ввод пути, загрузка/скачивание, новая папка, переименование, удаление, отмена | Файл/дерево, несколько объектов, существующий файл, обрыв и докачка, SHA-256, отмена без разрыва основного канала |
| Файлы / drag-and-drop | Проводник/левая панель → правая; правая → левая; экран → очередь загрузки в общую папку | Пустая область и подпапка, несколько файлов, отмена очереди; запрещённые NTFS-права |
| Server / Режим запуска | HKCU Run при входе текущего пользователя или вручную | Сохранить/отменить, повторный вход в Windows; это интерактивное приложение, не системная служба |
| Server / Настройки | Порт, трей, копирование ключа, журналы, общая папка | Сохранение/отмена, занятый порт, перезапуск слушателя, скрытие/восстановление из трея |
| Server / Права доступа | RemoteAdmin, Windows NT/AD, приглашения; пользователи и права | Смена метода отзывает текущий сеанс; парольный/NT-вход без согласия; приглашение только с согласием |
| Server / NT-права | Разрешения/запреты по SID, группы и пользователи, включение/удаление | Текущий/явный пользователь, неверный пароль, локальная/доменная группа, приоритет deny, отключённое правило, политики NTLM/Kerberos |
| Server / Помощь, чат, журнал, справка, выход | Приглашение с ограниченным сроком, чат с правом Chat, каталог логов, завершение | Истёкший/использованный код, чат без сеанса, завершение и повторный вход |
| Обновление MSI | Стабильный UpgradeCode, версия 0.5.0, установка поверх предыдущей | Обновить оба приложения; проверить сохранность пользователей, SID-правил, сертификата и адресной книги |

Telnet, голосовой чат, системная служба и перенос виртуальных файлов из программы прямо во внешний Проводник не реализованы и не представлены как рабочие команды. Протокол экрана остаётся JPEG/DXGI/GDI; показатели исходного ТЗ не заявляются.
